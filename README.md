### 🚀 Projetos

#### Nexus
Plataforma desenvolvida para arquitetos e pequenos escritórios, focada em gestão de projetos, clientes, finanças e equipe. O sistema foi construído em uma arquitetura **multitenant**, onde cada escritório possui seu próprio banco de dados, garantindo isolamento, segurança e escalabilidade. Conta com funcionalidades como controle financeiro mensal, organização de projetos por etapas, gerenciamento de equipe com permissões de acesso e portfólio público para venda de projetos prontos.

**Tecnologias:** Laravel, MySQL, jQuery, Tailwind

🔗 **Acessar:** [https://arqnexus.com.br](https://arqnexus.com.br/)
