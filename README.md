### 🚀 Projetos em Destaque

#### Nexus

Plataforma desenvolvida para arquitetos e pequenos escritórios, focada na gestão de projetos, clientes, finanças e equipe. O sistema foi construído utilizando uma arquitetura **multitenant**, permitindo que cada escritório possua seus próprios dados de forma isolada, garantindo maior segurança, organização e escalabilidade.

Entre os principais recursos da plataforma estão:

* Gestão completa de clientes e projetos;
* Controle financeiro mensal;
* Organização de projetos por etapas;
* Gerenciamento de equipe com níveis de acesso;
* Portfólio público para divulgação e venda de projetos;
* Ambiente exclusivo para cada escritório.

**Tecnologias:** Laravel, PHP, MySQL, jQuery, Tailwind CSS

🔗 **Acessar:** https://arqnexus.com.br
